# 算法答案

## LINUX-C-001 手写快速排序

```cpp
#include <vector>
#include <utility>

void quickSort(std::vector<int>& a, int l, int r) {
    if (l >= r) return;

    int pivot = a[l + (r - l) / 2];
    int i = l, j = r;

    while (i <= j) {
        while (a[i] < pivot) ++i;
        while (a[j] > pivot) --j;

        if (i <= j) {
            std::swap(a[i], a[j]);
            ++i;
            --j;
        }
    }

    if (l < j) quickSort(a, l, j);
    if (i < r) quickSort(a, i, r);
}
```

### 面试要点
- 平均复杂度 O(n log n)，最坏 O(n²)。
- 原地版本额外空间主要来自递归栈。
- 面试时必须解释边界推进，否则容易死循环。
