## ALG-C-002

**带哨兵单链表的插入、删除与销毁**

[返回例题](../嵌入式秋招八股文_算法.md#q-alg-c-002)

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;

int push_front(Node *head, int value)
{
    if (head == NULL)
        return -1;
    Node *node = malloc(sizeof *node);
    if (node == NULL)
        return -1;
    node->data = value;
    node->next = head->next;
    head->next = node;
    return 0;
}

int delete_value(Node *head, int value)
{
    if (head == NULL)
        return -1;

    Node *prev = head;
    while (prev->next != NULL) {
        if (prev->next->data == value) {
            Node *tmp = prev->next;
            prev->next = tmp->next;
            free(tmp);
            return 0;
        }
        prev = prev->next;
    }
    return -1;
}

void clear_list(Node *head)
{
    if (head == NULL)
        return;
    while (head->next != NULL) {
        Node *tmp = head->next;
        head->next = tmp->next;
        free(tmp);
    }
}
```

核心不变量：工作指针必须推进；删除时修改前驱的`next`，而不是只修改局部工作指针；失败返回应放在完整遍历结束后。

### 你曾经的易错点

循环始终检查`head->next`导致工作指针不推进；删除时只改`p`而未改`p->next`；失败返回过早。

### 尾插与头删补全

前面的实现包含头插、按值删除和清空；以下与同一 Node 定义合用，文件需包含 <stdlib.h>。

```c
int push_back(Node *head, int value) {
    if (!head) return -1;
    Node *node = malloc(sizeof *node);
    if (!node) return -1;
    node->data = value; node->next = NULL;
    Node *p = head;
    while (p->next) p = p->next;
    p->next = node;
    return 0;
}
int pop_front(Node *head, int *out) {
    if (!head || !out || !head->next) return -1;
    Node *tmp = head->next;
    *out = tmp->data;
    head->next = tmp->next;
    free(tmp);
    return 0;
}
```

哨兵可初始化为 Node head={0,NULL};；clear_list只释放有效节点，不释放调用者的head。

## ALG-C-003

**带哨兵链式队列入队与出队**

[返回例题](../嵌入式秋招八股文_算法.md#q-alg-c-003)

```c
typedef struct {
    Node *front;
    Node *rear;
} Queue;

int enqueue(Queue *q, int value)
{
    if (q == NULL || q->rear == NULL)
        return -1;

    Node *node = malloc(sizeof *node);
    if (node == NULL)
        return -1;
    node->data = value;
    node->next = NULL;

    q->rear->next = node;
    q->rear = node;
    return 0;
}

int dequeue(Queue *q, int *out)
{
    if (q == NULL || out == NULL || q->front == NULL ||
        q->front == q->rear)
        return -1;

    Node *tmp = q->front->next;
    *out = tmp->data;
    q->front->next = tmp->next;

    if (tmp == q->rear)
        q->rear = q->front;

    free(tmp);
    return 0;
}
```

出队删除的是哨兵后的首个有效节点，不是哨兵；通过`*out`修改调用者对象；删除最后一个有效节点后必须恢复`rear == front`这一空队列不变量。

### 你曾经的易错点

漏写`q->rear`；让`tmp`指向哨兵；写成`value = tmp->data`；删除末节点后未恢复`rear`。

本段依赖上一题 Node 类型并需 <stdlib.h>。可用 Node sentinel={0,NULL}; Queue q={&sentinel,&sentinel}; 初始化。销毁时反复出队释放有效节点，哨兵由调用者管理，不要free栈上的sentinel。

## LINUX-C-001

**手写快速排序**

[返回例题](../嵌入式秋招八股文_算法.md#q-linux-c-001)

```cpp
#include <vector>
#include <utility>

void quickSort(std::vector<int>& a, int l, int r) {
    if (l >= r) return;

    int pivot = a[l + (r - l) / 2];
    int i = l, j = r;

    while (i <= j) {
        while (a[i] < pivot) ++i;
        while (a[j] > pivot) --j;

        if (i <= j) {
            std::swap(a[i], a[j]);
            ++i;
            --j;
        }
    }

    if (l < j) quickSort(a, l, j);
    if (i < r) quickSort(a, i, r);
}
```

### 面试要点
- 平均复杂度 O(n log n)，最坏 O(n²)。
- 原地版本额外空间主要来自递归栈。
- 面试时必须解释边界推进，否则容易死循环。

空vector不要把size()-1作为无符号数传入；先if(!a.empty())再调用，且确认size可用int表示。递归栈平均O(log n)、最坏O(n)，不是O(1)额外空间。

## ALG-C-001

**空一格环形缓冲区的push/pop与计数**

[返回例题](../嵌入式秋招八股文_算法.md#q-alg-c-001)

```c
#define SIZE 8U

typedef struct {
    unsigned char buf[SIZE];
    size_t head;
    size_t tail;
} RingBuffer;

int ring_push(RingBuffer *rb, unsigned char value)
{
    if (rb == NULL)
        return -1;

    size_t next = (rb->head + 1U) % SIZE;
    if (next == rb->tail)
        return -1;

    rb->buf[rb->head] = value;
    rb->head = next;
    return 0;
}

int ring_pop(RingBuffer *rb, unsigned char *out)
{
    if (rb == NULL || out == NULL || rb->head == rb->tail)
        return -1;

    *out = rb->buf[rb->tail];
    rb->tail = (rb->tail + 1U) % SIZE;
    return 0;
}

size_t ring_count(const RingBuffer *rb)
{
    return (rb->head + SIZE - rb->tail) % SIZE;
}
```

空一格方案最大容量是`SIZE - 1`。索引推进必须环回；`rb->head++`最终可能越界。并发安全是另一个问题，不能由满空公式自动保证。

### 你曾经的易错点

漏写`rb->`成员前缀；使用`head++`而没有环回。

需包含 <stddef.h>，RingBuffer rb={0}; 初始化。ring_count要求非空有效对象。SIZE=8依次写满7个元素后head=7、tail=0；读两个后tail=2，再写两个后head=1、tail=2，重新满。

## CPP-C-001

**实现一个环形缓冲区的核心读写逻辑**

[返回例题](../嵌入式秋招八股文_算法.md#q-cpp-c-001)

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#define RB_CAPACITY 8

typedef struct {
    uint8_t data[RB_CAPACITY];
    size_t head;  // 下一次写入位置
    size_t tail;  // 下一次读取位置
    size_t count; // 当前元素数
} RingBuffer;

bool rb_push(RingBuffer *rb, uint8_t v) {
    if (!rb || rb->count == RB_CAPACITY) return false;
    rb->data[rb->head] = v;
    rb->head = (rb->head + 1) % RB_CAPACITY;
    rb->count++;
    return true;
}

bool rb_pop(RingBuffer *rb, uint8_t *out) {
    if (!rb || !out || rb->count == 0) return false;
    *out = rb->data[rb->tail];
    rb->tail = (rb->tail + 1) % RB_CAPACITY;
    rb->count--;
    return true;
}
```

### 面试要点
先说明“满/空如何区分”。上面使用 `count`，写起来最清楚；工程上还可采用牺牲一个槽位、单调递增读写索引等方式。

### 追问
- ISR 写、Task 读时是否线程安全？
- `%` 能不能优化掉？
- 如何做成无锁 SPSC？

初始化用 RingBuffer rb = {0};。这里的 count 方案只保证单线程逻辑正确，并不是ISR/任务并发安全版本。

## CPP-C-002

**指定区间链表反转**

[返回例题](../嵌入式秋招八股文_算法.md#q-cpp-c-002)

```cpp
struct ListNode {
    int val;
    ListNode *next;
};

ListNode* reverseBetween(ListNode* head, int left, int right) {
    if (!head || left == right) return head;

    ListNode dummy{0, head};
    ListNode *pre = &dummy;

    for (int i = 1; i < left; ++i) {
        pre = pre->next;
    }

    ListNode *cur = pre->next;
    for (int i = 0; i < right - left; ++i) {
        ListNode *move = cur->next;
        cur->next = move->next;
        move->next = pre->next;
        pre->next = move;
    }
    return dummy.next;
}
```

### 核心
dummy 节点用于统一 `left == 1` 的边界；时间复杂度 O(n)，额外空间 O(1)。

前提是1≤left≤right≤链表长度，函数没有为任意非法区间加检测。若对外接口允许非法输入，先验证长度/区间；不要在修改一半后才发现边界错误。
