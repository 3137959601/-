## E-C-001 寄存器位操作

假设 `reg` 为一个 32 位寄存器变量：

```c
reg |=  (1u << n);   // 置 1
reg &= ~(1u << n);   // 清 0
reg ^=  (1u << n);   // 翻转
```

- 如果 `n >= 32` 会怎样？

## E-K-002 为什么 ADC 采样常配合 DMA？

DMA 可以在外设与内存之间搬运数据，减少 CPU 对每个采样点逐次读寄存器的参与。高采样率场景下，它能降低 CPU 占用和中断频率；常结合循环 DMA、半传输/全传输中断和双缓冲，形成连续采集流水线。

## CTRL-C-001 非阻塞按键消抖状态机

```c
typedef enum {
    KEY_IDLE,
    KEY_DEBOUNCE_PRESS,
    KEY_PRESSED,
    KEY_DEBOUNCE_RELEASE
} KeyState;

typedef struct {
    KeyState state;
    uint32_t t0_ms;
} KeyDebounce;

bool key_update(KeyDebounce *k, bool raw_pressed, uint32_t now_ms) {
    const uint32_t debounce_ms = 20;

    switch (k->state) {
    case KEY_IDLE:
        if (raw_pressed) {
            k->state = KEY_DEBOUNCE_PRESS;
            k->t0_ms = now_ms;
        }
        break;

    case KEY_DEBOUNCE_PRESS:
        if (!raw_pressed) {
            k->state = KEY_IDLE;
        } else if ((uint32_t)(now_ms - k->t0_ms) >= debounce_ms) {
            k->state = KEY_PRESSED;
            return true; // 仅在确认按下时产生一次事件
        }
        break;

    case KEY_PRESSED:
        if (!raw_pressed) {
            k->state = KEY_DEBOUNCE_RELEASE;
            k->t0_ms = now_ms;
        }
        break;

    case KEY_DEBOUNCE_RELEASE:
        if (raw_pressed) {
            k->state = KEY_PRESSED;
        } else if ((uint32_t)(now_ms - k->t0_ms) >= debounce_ms) {
            k->state = KEY_IDLE;
        }
        break;
    }
    return false;
}
```

### 为什么比 `delay_ms(20)` 好？
它不会阻塞主循环或任务，可以同时处理通信、控制和其他外设。

## CTRL-D-002 修复阻塞式控制循环

### 常见坏味道
- 主循环大量 `delay`
- 一个状态等待传感器时阻塞整个系统
- while 等待标志位且无超时
- ISR 内执行长耗时逻辑

### 优化
拆成显式状态机 + 时间戳 + 事件驱动；所有等待都设置超时；ISR 只做最小工作并通知任务。
