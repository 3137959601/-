## 整理规则

- 一个知识点一个独立小节，保留概念、机制、代码、适用条件及易错边界，不再按复习批次分大组。
- 例题写清代码/场景、必要假设、输入输出和具体问题；题后只放一个“查看答案”链接，直接落到解析正文。
- 不设置独立训练题库、能力点、难度、任务或掌握等级字段；真实历史错误放在对应答案中的“你曾经的易错点”，不把未答题记为错题。
- 新内容加入对应知识小节，新增知识才另开独立小节。题目用 `### Q-题号`、答案用 `## 题号` 作为真正的Markdown标题；链接直接指向标题生成的片段，不使用隐藏的HTML锚点。题号保持不变，描述性名称放在标题下方。
- 答案包含逐项结论、原因及必要代码，不以一句提示代替解析。完整程序与代码片段需明确区分；平台相关结论注明假设。
- 本次补充用于材料整理，不等于实测或闭卷掌握。计划、学习状态、历史快照不因整理自动改变。
